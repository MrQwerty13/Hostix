# ADR 0002: Поддерживаемые Moby SDK модули для DockerRuntime

- Статус: принято
- Дата: 2026-08-23

## Контекст

Первоначальный план указывает импорт `github.com/docker/docker/client`. Начиная
с Docker Engine 29 этот Go-модуль объявлен устаревшим и больше не обновляется.
Поддерживаемый публичный API разделён на два независимо версионируемых модуля:

- `github.com/moby/moby/client` — клиент Docker Engine API;
- `github.com/moby/moby/api` — общие API-типы.

Импорт корневого `github.com/moby/moby/v2` не подходит: он предназначен для
сборки движка и не имеет гарантий стабильности для библиотечных потребителей.

## Решение

`DockerRuntime` использует `github.com/moby/moby/client` и
`github.com/moby/moby/api`. Клиент создаётся из переменных окружения Docker и
использует автоматическое согласование версии Engine API.

Взаимодействие с SDK скрыто внутри `internal/runtime/docker`; остальные пакеты
зависят от интерфейса `runtime.Runtime` и небольшого контракта сборки образа.

## Последствия

Положительные:

- Hostix использует актуальный поддерживаемый путь SDK.
- Версия API автоматически согласуется с Docker daemon.
- Миграция SDK не протекает в CLI и определение стека.

Отрицательные:

- Реализация отличается от старого пути импорта в первоначальном плане.
- Модули client и api необходимо обновлять согласованно.
- До выпуска v1 клиентский модуль может содержать несовместимые изменения.
