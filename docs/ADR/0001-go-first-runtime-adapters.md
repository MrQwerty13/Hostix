# ADR 0001: Go-first архитектура с runtime-адаптерами

- Статус: принято
- Дата: 2026-08-23

## Контекст

Hostix должен одинаково управлять Docker-контейнерами и Tart VM. В плане также
предусмотрен C++ для потенциально дорогой обработки метрик и логов. Раннее
добавление cgo усложнит сборку, тестирование и выпуск бинарников до появления
данных о реальной производительности.

## Решение

CLI, оркестрация, конфигурация, определение стека и первая реализация метрик
пишутся на Go. Docker и Tart подключаются как адаптеры интерфейса `Runtime`.
C++ модуль создаётся только после профилирования Go-реализации и фиксации
измеримого bottleneck отдельным ADR.

## Последствия

Положительные:

- MVP имеет простой кроссплатформенный pipeline сборки.
- Runtime-адаптеры можно тестировать независимо.
- Решение о cgo будет опираться на измерения.

Отрицательные:

- Общий интерфейс не устраняет фундаментальные различия Docker и Tart.
- Часть логики ожидания VM и SSH останется специфичной для Tart.
- Возможное позднее добавление C++ потребует отдельного ABI и сборочного контура.
